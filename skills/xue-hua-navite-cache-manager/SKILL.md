# xue-hua-navite-cache-manager

Provide idiomatic integration patterns, platform setup rules, and best practices for the `xue_hua_navite_cache_manager` Flutter plugin across Android, iOS, macOS, Windows, Linux, and Web.

## When to Use

- Configuring global disk cache quotas, eviction policies (`LRU`, `LFU`, `FIFO`, `ttlOnly`), HTTP timeouts, and default headers (`CacheManagerConfig`)
- Fetching and caching remote images, audio, video, PDFs, or arbitrary files (`downloadFile`, `getSingleFile`, `prefetch`, `prefetchAll`, `cancelDownload`)
- Validating downloaded files with native `MD5` or `SHA-256` checksums (`CacheChecksumAlgorithm`)
- Storing in-memory bytes or existing local files directly into the managed cache (`putBytes`, `putFile`)
- Querying cached entries offline without triggering network requests (`getFileFromCache`, `readCacheBytes`, `containsKey`)
- Protecting critical assets from quota eviction (`setPinned`) or purging entries by tag, expiration, or byte limit (`removeFile`, `removeByTag`, `removeExpired`, `trimToSize`, `clearAll`)
- Inspecting live cache telemetry and platform storage capabilities (`getStats`, `listEntries`, `getCapabilities`, `progressStream`, `watchProgress`)

## Guidelines

1. Access `XueHuaNaviteCacheManager.instance` and call `configure(CacheManagerConfig(...))` during application startup before issuing download requests.
2. Subscribe to `XueHuaNaviteCacheManager.instance.progressStream` (or `watchProgress(keyOrUrl)`) to render real-time transfer progress and cancel the `StreamSubscription` in `dispose()`.
3. Prefer `downloadFile(CacheRequest(...))` when you need to inspect `result.source` (`cacheHit`, `revalidated`, `networkDownload`, `staleCacheFallback`) and `result.httpStatusCode`; use `getSingleFile(url)` when you only need the `CacheEntry`.
4. Group related assets using the `tag` parameter (for example, `'avatars'`, `'course_audio'`, `'banners'`) so you can invalidate an entire category in one call with `removeByTag(tag)`.
5. Set `pinned: true` (or call `setPinned(keyOrUrl, pinned: true)`) on essential offline resources so automatic `LRU`/`LFU`/`FIFO` quota trimming skips them.
6. On Web targets, `entry.filePath` is a browser `Blob` object URL or `CacheStorage` URI rather than a POSIX filesystem path (`capabilities.supportsFileSystemPaths` is `false`). Use `readCacheBytes(keyOrUrl)` or pass `entry.filePath` to `Image.network` on Web instead of `dart:io` `File(entry.filePath)`.
7. On macOS, ensure `com.apple.security.network.client` is enabled in both `macos/Runner/DebugProfile.entitlements` and `macos/Runner/Release.entitlements`.

## Examples

### Global initialization and network file caching

```dart
import 'package:xue_hua_navite_cache_manager/xue_hua_navite_cache_manager.dart';

final cacheManager = XueHuaNaviteCacheManager.instance;

Future<void> initCache() async {
  await cacheManager.configure(
    const CacheManagerConfig(
      maxDiskCacheBytes: 200 * 1024 * 1024, // 200 MB
      maxEntries: 1000,
      defaultTtlSeconds: 7 * 24 * 3600, // 7 days
      evictionPolicy: CacheEvictionPolicy.lru,
      cacheSubdirectory: 'app_media_cache',
      respectHttpCacheHeaders: true,
      autoTrimOnWrite: true,
    ),
  );

  final result = await cacheManager.downloadFile(
    const CacheRequest(
      url: 'https://flutter.github.io/assets-for-api-docs/assets/widgets/owl.jpg',
      tag: 'animals',
      fallbackToCacheOnError: true,
      checksumAlgorithm: CacheChecksumAlgorithm.sha256,
    ),
  );

  // Inspect cache source: cacheHit, revalidated (HTTP 304), networkDownload, or staleCacheFallback
  print('Source: ${result.source.wireValue}, Path: ${result.filePath}');
}
```

### Real-time progress tracking and selective eviction

```dart
import 'dart:async';
import 'dart:typed_data';
import 'package:xue_hua_navite_cache_manager/xue_hua_navite_cache_manager.dart';

Future<void> manageCacheLifecycle() async {
  final cache = XueHuaNaviteCacheManager.instance;

  final sub = cache.watchProgress('https://example.com/manual.pdf').listen((event) {
    final pct = ((event.progress ?? 0) * 100).toStringAsFixed(1);
    print('[${event.state.wireValue}] $pct% (${event.bytesReceived}/${event.totalBytes})');
  });

  // Store generated bytes directly into cache as a pinned entry
  await cache.putBytes(
    key: 'offline_config_v1',
    bytes: Uint8List.fromList('{"theme":"dark"}'.codeUnits),
    fileExtension: 'json',
    mimeType: 'application/json',
    tag: 'config',
    pinned: true,
  );

  // Evict expired entries or trim to 50 MB while preserving pinned items
  await cache.removeExpired();
  await cache.trimToSize(50 * 1024 * 1024);

  final stats = await cache.getStats();
  print('Entries: ${stats.totalEntries}, Hit rate: ${(stats.hitRate * 100).toStringAsFixed(1)}%');

  await sub.cancel();
}
```

## Gotchas

- **Web (`CacheStorage` & CORS)**: `window.caches` and `fetch()` require remote servers to return valid CORS headers when fetching cross-origin resources in browsers. Always use `readCacheBytes()` when raw bytes are needed across all 6 platforms.
- **macOS App Sandbox**: Outbound downloads fail with `NSURLErrorNotConnectedToInternet` (`-1009`) or `Operation not permitted` if `com.apple.security.network.client` is missing from `DebugProfile.entitlements` or `Release.entitlements`.
- **Linux Runtime Dependencies**: Uses GLib `GChecksum` for native hashing and `curl` for HTTP transfers; ensure `curl` and standard CA certificates (`ca-certificates`) are installed on minimal Linux containers.
